# algoritmit_aine

Tämä on Helsingin yliopiston kurssin Algoritmit ja Tekoäly Harjoitustyon palautus-repositorio

## ohjeet

- Kun olet kloonannut repositorion, aja:
`poetry install --no-root`
- Jonka jälkeen voit testata algoritmia ajamalla python (algoritmin nimi), kuten:
`python astar.py`
- Piirrä aloitus- ja lopetus-ruudut, jonka jälkeen voit piirtää esteitä. Voit pyyhkiä ruutuja oikealla hiirinäppäimellä.
